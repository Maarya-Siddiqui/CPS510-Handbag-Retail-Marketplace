HANDBAG MARKETPLACE - quick start
1. In SQL Developer run schema_oracle.sql (fresh database), OR migration_bcnf.sql (tables already exist).
2. pip install -r requirements.txt
3. Set DB_USER, DB_PASSWORD, DB_DSN (environment variables, or edit the top of app.py).
4. python3 app.py   ->  open http://127.0.0.1:5000 in your browser
   (Do NOT open static/index.html directly or with Live Preview: the data comes from app.py.)
