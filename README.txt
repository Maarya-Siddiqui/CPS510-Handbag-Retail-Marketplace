HANDBAG MARKETPLACE - quick start
1. In SQL Developer run schema_oracle.sql (fresh database).
2. pip install -r requirements.txt
3. Edit DB_USER, DB_PASSWORD, DB_DSN at the top of app.py (same details as your SQL Developer connection).
4. python app.py   ->  open http://127.0.0.1:5000
